# AI Generated Podcast

## Tools & Platforms

For this assignment, I used a range of generative AI.

- ChatGPT
  - Script and Prompt refinment

- Wondercraft.ai
  - Audio Generation

## Challenges

I did not run into many challenges, other than finding a tool that is both free and halfway decent. It just took some searching around to find platforms that worked for me.

## Ethical Considerations

Since the script itself is generated by AI, an ethical consideration is to fact check the information within, as well as check for bias. This podcast itself discussed AI bias and ethics, so I did not change much as a omage to AIs bias. I simply refined it so that each side had an appropriate viewpoint, and the correct structure.

## What did I learn

I learned that AI can be usefull. Also, the original script was way too long, and some parts sounded very unnatural so I had to refine everything multiple times before I was able to start generating the audio.

Overall, this was cheaper to me, the consumer, since I paid $0.00 for this episode, while had I done this myself I would have had to pay for equipment, staff, etc... So in this example, it was simpler and cheaper, but I would recomend just doing the work. This took too long...
